# The Mātaṅgī Codex

A responsive study-guide website for Śrī Rāja Śyāmalā / Mātaṅgī, sacred speech, symbolic consciousness, music, mantra, media, and tantric expression.

## Open locally

Open `index.html` in a browser.

## GitHub Pages

This is a static website. It can be deployed from the repository root using GitHub Pages.
